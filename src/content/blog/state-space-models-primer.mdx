A transfer function, introduced in the [first entry](/blog/introduction-to-control-systems), describes how one input affects one output. A state-space model keeps track of the internal variables as well, which makes it a natural fit for systems with several inputs and outputs and for computation. This entry defines the state of a system, builds a state-space model of a mass on a spring, relates it to the transfer function of the same system and shows how the eigenvalues of one matrix decide whether the free response decays. It builds on the transfer function and poles (first entry, Section 3) and on the first-order plant of the [second entry](/blog/feedback-and-system-behavior).

Vectors are column vectors. The example uses SI units: mass in kilograms, force in newtons, displacement in meters, time in seconds. The code uses Python 3 and NumPy.

## 1. The state of a system

A transfer function relates input to output for a system that starts at rest. It says nothing about what happens when the system starts elsewhere, for example a mass released from a displaced position, and it hides any internal variable that does not appear in the output. Both are needed to analyze stability and to design controllers that use internal measurements.

The **state** of a system is a set of variables whose present values, together with the input from now on, determine its entire future behavior. The state is the system's memory: everything about the past that matters for the future. For the first-order plant of the second entry, $\dot{x} = -a\,x + b\,u$, the single variable $x$ is a state: its present value and the input fix the solution of the differential equation from now on. A system described by an $n$-th order differential equation needs $n$ state variables, because the solution of such an equation is fixed by $n$ initial conditions.

## 2. From a differential equation to state equations

<Figure caption="The mass-spring-damper: stiffness k, damping coefficient c, applied force u and displacement q.">

</Figure>

A mass $m$ on a spring with stiffness $k$ and a damper with coefficient $c$, driven by a force $u$, obeys

$$
m\ddot{q} + c\dot{q} + kq = u,
$$

where $q$ is the displacement from the position at which the spring is relaxed. This is a second-order equation, so it needs two state variables. For the mass, position and velocity are enough: knowing where it is, how fast it moves and the force from now on fixes its motion. To get a first-order vector equation, choose these as the state variables $x_1 = q$ and $x_2 = \dot{q}$. Then $\dot{x}_1 = x_2$ and $\dot{x}_2 = (u - c x_2 - k x_1)/m$, which in matrix form is

$$
\dot{x} =
\begin{bmatrix} 0 & 1 \\ -k/m & -c/m \end{bmatrix} x
+ \begin{bmatrix} 0 \\ 1/m \end{bmatrix} u,
\qquad
y = \begin{bmatrix} 1 & 0 \end{bmatrix} x .
$$

The first row says only that velocity is the derivative of position; the second row is Newton's second law. The output $y$ is the displacement, the quantity a position sensor would measure.

## 3. The general linear time-invariant form

The general linear time-invariant form, for a system with $n$ states, $m$ inputs and $p$ outputs (here $m$ is a count of inputs, not the mass), is

$$
\dot{x} = Ax + Bu, \qquad y = Cx + Du.
$$

| Symbol | Meaning | Size for $n$ states, $m$ inputs, $p$ outputs |
| --- | --- | --- |
| $x$ | State vector | $n \times 1$ |
| $u$ | Input vector | $m \times 1$ |
| $y$ | Output vector | $p \times 1$ |
| $A$ | How the state evolves on its own | $n \times n$ |
| $B$ | How inputs enter the state | $n \times m$ |
| $C$ | How the state appears in the output | $p \times n$ |
| $D$ | Direct path from input to output | $p \times m$ |

In the example $D = 0$, since the force does not affect the displacement instantaneously. The first-order plant of the second entry is the case $n = m = p = 1$ with $A = -a$, $B = b$, $C = 1$ and $D = 0$.

The choice of state is not unique. Any invertible matrix $T$ defines new state variables $z = Tx$, for example the displacement in millimeters or a combination of position and velocity, and substituting $x = T^{-1}z$ gives a model of the same form,

$$
\dot{z} = TAT^{-1}z + TBu, \qquad y = CT^{-1}z + Du.
$$

The input-output behavior is unchanged, and so are the eigenvalues of the system matrix, because $\det(sI - TAT^{-1}) = \det\bigl(T(sI - A)T^{-1}\bigr) = \det(sI - A)$. The eigenvalues are therefore properties of the system, not of the coordinates chosen to describe it. The [fourth entry](/blog/stability-and-eigenvalues) uses this freedom to choose coordinates in which the equations separate.

## 4. Stability from the eigenvalues of A

### 4.1 The free response

With $u = 0$ the solution is $x(t) = e^{At}x(0)$, where $e^{At}$ is the **matrix exponential**, defined by the same power series as the scalar exponential, $e^{At} = I + At + (At)^2/2! + \cdots$, with $I$ the identity matrix; the [next entry](/blog/stability-and-eigenvalues) shows how to compute it from the eigenvalues and eigenvectors of $A$. Differentiating the series term by term gives $A\,e^{At}$, so $x(t)$ satisfies $\dot{x} = Ax$, and at $t = 0$ the series is $I$, so the initial condition holds.

The solution decays to zero for every initial condition if and only if every eigenvalue of $A$ has a negative real part. One direction of the reason fits in a line. If $v$ is an eigenvector of $A$ with eigenvalue $\lambda$, so that $Av = \lambda v$, then $x(t) = e^{\lambda t}v$ satisfies $\dot{x} = \lambda e^{\lambda t}v = A\,x$: a system started along $v$ stays along $v$ and is scaled by $e^{\lambda t}$, exactly like the scalar plant of the second entry. If the real part of $\lambda$ is zero or positive, that response does not decay. The [fourth entry](/blog/stability-and-eigenvalues) proves the other direction by writing every free response as a sum of such terms.

### 4.2 The characteristic polynomial

The eigenvalues of $A$ are the roots of its **characteristic polynomial** $\det(sI - A)$, written in the same variable $s$ as a transfer function, for a reason Section 5 explains. For the example it is

$$
\det(sI - A) = s^2 + \frac{c}{m}\,s + \frac{k}{m},
$$

with roots

$$
s = \frac{-c \pm \sqrt{c^2 - 4mk}}{2m}.
$$

For positive $m$, $c$ and $k$ both roots have negative real part, so the damped oscillator is stable. When $c^2 < 4mk$ the roots form a complex pair, and the system oscillates while it decays. With negative damping ($c < 0$, a mechanism that feeds energy in rather than removing it), the real part becomes positive and the oscillation grows.

### 4.3 A numerical example

For a numerical example take $m = 1$ kg, $c = 0.5$ N·s/m and $k = 4$ N/m:

```python
import numpy as np

m, c, k = 1.0, 0.5, 4.0
A = np.array([[0.0, 1.0],
              [-k / m, -c / m]])

print(np.linalg.eigvals(A))   # approximately -0.25 + 1.984j and -0.25 - 1.984j
```

<Figure caption="Eigenvalues of A for m = 1, c = 0.5 and k = 4. Both lie in the left half-plane, so the free response decays while it oscillates.">
  <EigenvaluePlot />
</Figure>

The real part, $-c/(2m) = -0.25$ (in 1/s), sets the decay rate. The imaginary part, $\sqrt{4mk - c^2}/(2m) \approx 1.984$, sets the oscillation frequency in radians per second.

## 5. Input-output and state-space forms of the same system

The two descriptions of the first entry and this one describe the same system. Transforming $m\ddot{q} + c\dot{q} + kq = u$ with the mass at rest ($q(0) = \dot{q}(0) = 0$) gives $(ms^2 + cs + k)\,Q(s) = U(s)$, so the transfer function from force to displacement is

$$
G(s) = \frac{1}{ms^2 + cs + k} = \frac{1}{s^2 + 0.5\,s + 4} \quad\text{for the example}.
$$

Its denominator, divided by $m$, is the characteristic polynomial of Section 4.2, so the poles of $G(s)$ are the eigenvalues of $A$. Its steady-state gain is $G(0) = 1/k = 0.25$ m/N: a constant force of 1 N displaces the mass by 0.25 m, the deflection of the spring alone. Up to the factor $1/k$, $G(s)$ is the second-order benchmark of the first entry's Section 4.2; the [fourth entry](/blog/stability-and-eigenvalues) reads its natural frequency and damping ratio from the eigenvalues.

The two forms are not equivalent in every respect.

- **From state space to transfer function** there is always exactly one answer. The fourth entry derives the general formula $G(s) = C(sI - A)^{-1}B + D$.
- **From transfer function to state space** there are infinitely many answers, one for every choice of coordinates in Section 3.
- **Hidden behavior.** A state-space model can contain a mode that the input does not move or the output does not show. Such a mode is invisible in the transfer function, and the fourth entry shows that it can be unstable while $G(s)$ looks stable.

The state-space form is the more complete description, and the transfer function the more compact one when only the input-output behavior matters.

## 6. Assumptions and limits

The same $(A, B, C, D)$ form describes a single mass or a robot arm with many joints, and standard linear algebra routines operate on it directly. It does so under assumptions that a real system satisfies only approximately.

- **Linearity.** A real spring that stiffens with extension, a damper that saturates or friction that depends on the direction of motion makes the equations nonlinear. A linear model is then obtained by **linearization** around an operating point, and its conclusions hold only near that point; the fourth entry treats this for a pendulum.
- **Time invariance.** The matrices are constant. If a parameter changes during operation, such as the mass carried by a robot arm, the model is valid only for the parameter values it was built with.
- **A finite number of states.** A flexible beam, a long pipe or a pure time delay has, strictly, infinitely many states. A model with $n$ states approximates such a system, and the approximation must be checked over the range of speeds the controller will excite.

## 7. Summary

| Concept | Result |
| --- | --- |
| State | Variables whose present values and the future input determine the future behavior; $n$ of them for an $n$-th order system |
| State-space form | $\dot{x} = Ax + Bu$, $y = Cx + Du$; for the mass-spring-damper, $x = [q \;\; \dot{q}]^\top$ |
| Coordinates | Any invertible $T$ gives an equivalent model; the eigenvalues of $A$ do not change |
| Free response | $x(t) = e^{At}x(0)$, with the matrix exponential defined by its power series |
| Stability | The free response decays for every initial condition if and only if every eigenvalue of $A$ has a negative real part |
| Link to the transfer function | The eigenvalues are the roots of $\det(sI - A)$; for the example they are the poles of $G(s) = 1/(ms^2 + cs + k)$ |

The state-space form turns questions about a system's behavior into questions about one matrix. This entry stated the eigenvalue test and proved half of it. The [next entry](/blog/stability-and-eigenvalues) proves the rest by decomposing the free response into modes, explains what else the eigenvalues say about the response, and shows where they stop being enough.
