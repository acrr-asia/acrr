A transfer function, introduced in the [first entry](/blog/introduction-to-control-systems), describes how one input affects one output. A state-space model keeps track of the internal variables as well, which makes it a natural fit for systems with several inputs and outputs and for computation. This primer builds a state-space model from a familiar example and shows what its main matrix tells you.

## From a differential equation to states

<Figure caption="The mass-spring-damper: stiffness k, damping coefficient c, applied force u and displacement q.">
  <MassSpringDamper />
</Figure>

A mass $m$ on a spring with stiffness $k$ and a damper with coefficient $c$, driven by a force $u$, obeys

$$
m\ddot{q} + c\dot{q} + kq = u,
$$

where $q$ is the displacement. This is a second-order equation. The **state** of a system is a set of variables whose present values, together with the input from now on, determine its entire future behavior. For the mass, position and velocity are enough: knowing where it is, how fast it moves and the force from now on fixes its motion. To get a first-order vector equation, choose these as the state variables $x_1 = q$ and $x_2 = \dot{q}$. Then $\dot{x}_1 = x_2$ and $\dot{x}_2 = (u - c x_2 - k x_1)/m$, which in matrix form is

$$
\dot{x} =
\begin{bmatrix} 0 & 1 \\ -k/m & -c/m \end{bmatrix} x
+ \begin{bmatrix} 0 \\ 1/m \end{bmatrix} u,
\qquad
y = \begin{bmatrix} 1 & 0 \end{bmatrix} x .
$$

The general linear time-invariant form, for a system with $n$ states, $m$ inputs and $p$ outputs (here $m$ is a count of inputs, not the mass), is

$$
\dot{x} = Ax + Bu, \qquad y = Cx + Du.
$$

| Symbol | Meaning | Size for $n$ states, $m$ inputs, $p$ outputs |
| --- | --- | --- |
| $x$ | State vector | $n \times 1$ |
| $u$ | Input vector | $m \times 1$ |
| $y$ | Output vector | $p \times 1$ |
| $A$ | How the state evolves on its own | $n \times n$ |
| $B$ | How inputs enter the state | $n \times m$ |
| $C$ | How the state appears in the output | $p \times n$ |
| $D$ | Direct path from input to output | $p \times m$ |

In the example $D = 0$, since the force does not affect the displacement instantaneously.

## Stability from the eigenvalues of A

With $u = 0$ the solution is $x(t) = e^{At}x(0)$, where $e^{At}$ is the **matrix exponential**, defined by the same power series as the scalar exponential, $e^{At} = I + At + (At)^2/2! + \cdots$, with $I$ the identity matrix; the [next entry](/blog/stability-and-eigenvalues) shows how to compute it from the eigenvalues and eigenvectors of $A$. The solution decays to zero for every initial condition if and only if every eigenvalue of $A$ has a negative real part. The eigenvalues of $A$ are the roots of its **characteristic polynomial** $\det(sI - A)$, written in the same variable $s$ as a transfer function, for a reason the next entry explains. For the example it is

$$
\det(sI - A) = s^2 + \frac{c}{m}\,s + \frac{k}{m},
$$

with roots

$$
s = \frac{-c \pm \sqrt{c^2 - 4mk}}{2m}.
$$

For positive $m$, $c$ and $k$ both roots have negative real part, so the damped oscillator is stable. When $c^2 < 4mk$ the roots form a complex pair, and the system oscillates while it decays.

For a numerical example take $m = 1$ kg, $c = 0.5$ N·s/m and $k = 4$ N/m, with time in seconds (the code uses Python 3 and numpy):

```python
import numpy as np

m, c, k = 1.0, 0.5, 4.0
A = np.array([[0.0, 1.0],
              [-k / m, -c / m]])

print(np.linalg.eigvals(A))   # approximately -0.25 + 1.984j and -0.25 - 1.984j
```

<Figure caption="Eigenvalues of A for m = 1, c = 0.5 and k = 4. Both lie in the left half-plane, so the free response decays while it oscillates.">
  <EigenvaluePlot />
</Figure>

The real part, $-c/(2m) = -0.25$, sets the decay rate. The imaginary part, $\sqrt{4mk - c^2}/(2m) \approx 1.984$, sets the oscillation frequency in radians per second.

## Why it is worth the extra notation

The same $(A, B, C, D)$ form describes a single mass or a robot arm with many joints, and standard linear algebra routines operate on it directly. The limits matter too. The model above is linear, so a real spring that stiffens or a damper that saturates needs linearization around an operating point, and the conclusions then hold only near that point.
