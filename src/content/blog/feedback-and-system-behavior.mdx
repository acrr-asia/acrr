Feedback is the central idea of control engineering: measure what a system is doing, compare it with what is wanted, and let the difference drive the input. This entry uses the smallest model that shows the effect, a first-order system, to see exactly what changes when the loop is closed. When the plant is known exactly, feedback does not make this system more accurate. It makes it faster, it can make an unstable plant stable, and it makes the output far less sensitive to errors in the model and to disturbances.

The entry builds on the [first entry](/blog/introduction-to-control-systems), whose Sections 1 and 3 introduce the loop, the transfer function and its poles; the plant used here is the first-order example of the first entry's Section 3.3. The signals $x$, $u$ and $r$ are in arbitrary but consistent units, time is in seconds, and $a$ is in 1/s. The code uses Python 3 with the standard library only.

## 1. The plant without feedback

### 1.1 A first-order plant

Take a plant described by

$$
\dot{x}(t) = -a\,x(t) + b\,u(t), \qquad a > 0,\; b > 0,
$$

where $x$ is the output, $u$ is the input, and $a$ and $b$ are constants. It is the first-order example of the first entry with the output called $x$. With no input, $x$ decays as $e^{-at}$, so the time constant is $\tau = 1/a$; its transfer function from $u$ to $x$ is $b/(s + a)$, with a single **pole** at $s = -a$.

### 1.2 Open-loop control

In open loop the input is chosen without looking at $x$. For a constant reference $r$ the natural choice is the input that makes $\dot{x} = 0$ at $x = r$, which is $u = (a/b)\,r$. With $a = b = 1$ this is $u = r$, and the output settles at $x_{ss} = r$ with time constant $1$ s. On the nominal plant, then, open loop is already exact. Its weakness is that it works only if $a$ and $b$ are known exactly and nothing pushes on the plant: if the plant changes, or a disturbance acts on it, the input cannot react.

## 2. Closing the loop with proportional feedback

### 2.1 The closed-loop equation

Now let the input depend on the error between a constant reference $r$ and the measured output:

$$
u(t) = k\,\bigl(r - x(t)\bigr), \qquad k > 0.
$$

This is **proportional feedback**: the input is the error multiplied by a constant gain $k$.

Substituting into the plant gives the closed-loop equation

$$
\dot{x}(t) = -(a + bk)\,x(t) + bk\,r.
$$

### 2.2 Speed: the pole moves left

The decay rate changed from $a$ to $a + bk$, so the closed-loop time constant is $\tau_{cl} = 1/(a + bk)$. A larger gain makes the system respond faster. In the language of the first entry, the closed loop from $r$ to $x$ has the transfer function $bk/(s + a + bk)$, so feedback moves the pole from $s = -a$ to $s = -(a + bk)$, further to the left, where its term $e^{-(a + bk)t}$ decays faster.

### 2.3 The steady-state offset

For a constant reference the output settles where $\dot{x} = 0$:

$$
x_{ss} = \frac{bk}{a + bk}\,r, \qquad r - x_{ss} = \frac{a}{a + bk}\,r.
$$

The steady-state error shrinks as $k$ grows but never reaches zero with proportional action alone. To hold $x = r$ the plant needs the input $u = (a/b)\,r$, but $u = k(r - x)$ is zero whenever the error is zero. Supplying the required input with zero error takes an **integrator**: an element whose output is the time integral of the error, so it can stay at a nonzero value once the error has vanished. This loop has none.

The table compares the closed loop with the open loop of Section 1.2 for $a = 1$ and $b = 1$, on the nominal plant.

| Controller | Pole | Time constant (s) | Steady-state error (fraction of $r$) |
| --- | --- | --- | --- |
| Open loop, $u = r$ | -1 | 1 | 0 |
| Feedback, $k = 1$ | -2 | 0.5 | 0.50 |
| Feedback, $k = 4$ | -5 | 0.2 | 0.20 |
| Feedback, $k = 9$ | -10 | 0.1 | 0.10 |

</Figure>

Read the last column carefully. On the nominal plant the open loop has no error at all, so proportional feedback does not improve accuracy here. What it changes is speed: the time constant falls from 1 s to 0.5, 0.2 and 0.1 s. The reason to accept the offset appears in Section 4, when the plant is not exactly what the model says.

### 2.4 Feedback can make an unstable plant stable

The same formula shows that feedback can change stability itself. Suppose the plant were unstable, with $a < 0$, so that $x$ grows without input: with $a = -1$ and $b = 1$, any small initial value grows as $e^{t}$. No constant open-loop input can hold such a plant at a reference, because any small error from the intended equilibrium grows. With feedback the closed-loop pole is at $s = -(a + bk)$, which lies in the left half-plane whenever

$$
a + bk > 0, \qquad\text{that is}\qquad k > -a/b = 1.
$$

With $k = 4$ the pole is at $-3$ and the closed loop settles, with time constant $1/3$ s, at $x_{ss} = bk\,r/(a + bk) = 4r/3$. The formula of Section 2.3 still holds, but because $a$ is negative the output now settles above the reference. With $k < 1$ the loop remains unstable. Feedback has turned a plant that cannot be operated in open loop into a stable system, provided the gain exceeds a minimum set by the plant.

## 3. A short simulation

The algebra can be checked numerically with the **explicit Euler method**, which advances $\dot{x} = f(x)$ in small time steps $\Delta t$ by $x \leftarrow x + \Delta t\,f(x)$. With $k = 4$ and $r = 1$ the table predicts $x_{ss} = 0.8$. The step of 0.001 s is 200 times shorter than the closed-loop time constant of 0.2 s, small enough for the method to follow the solution closely.

```python
a, b, k, r = 1.0, 1.0, 4.0, 1.0
dt, x = 0.001, 0.0

for _ in range(int(5 / dt)):       # simulate 5 seconds
    u = k * (r - x)                # proportional feedback
    x += dt * (-a * x + b * u)     # explicit Euler step

print(round(x, 3))                 # 0.8
```

Running this prints `0.8`, matching $bk/(a + bk)$.

## 4. When the plant or the load changes

### 4.1 Two perturbations

Two perturbations show what the feedback buys. Both use $k = 4$, $r = 1$ and the open-loop input $u = r$, which was designed for $a = b = 1$.

**A plant that decays 20% faster** ($a = 1.2$). Open loop settles at $x_{ss} = bu/a = 1/1.2 \approx 0.833$. Closed loop settles at $bk\,r/(a + bk) = 4/5.2 \approx 0.769$.

**A constant disturbance $d$** added to the plant, so that $\dot{x} = -a\,x + b\,u + d$. In open loop the output settles at $(bu + d)/a$, so the disturbance moves it by $d/a$. In closed loop the equation becomes $\dot{x} = -(a + bk)\,x + bk\,r + d$, and the disturbance moves the output by only $d/(a + bk)$. For $a = b = 1$ and $k = 4$ that is one fifth as much.

```python
def settle(a, control, d=0.0, b=1.0, dt=0.001, T=10.0):
    x = 0.0
    for _ in range(int(T / dt)):
        x += dt * (-a * x + b * control(x) + d)   # explicit Euler step
    return x

r = 1.0
open_loop = lambda x: r                 # u = r, exact when a = b = 1
closed_loop = lambda x: 4.0 * (r - x)   # k = 4

cases = [("nominal", 1.0, 0.0), ("a = 1.2", 1.2, 0.0), ("d = 0.2", 1.0, 0.2)]
for label, a, d in cases:
    print(label, round(settle(a, open_loop, d), 3), round(settle(a, closed_loop, d), 3))
```

The three lines it prints are collected below, with the shift from the nominal output in brackets.

| Case | Open loop, $u = r$ | Closed loop, $k = 4$ |
| --- | --- | --- |
| Nominal ($a = 1$, $d = 0$) | 1.000 | 0.800 |
| Plant changed ($a = 1.2$) | 0.833 (-0.167) | 0.769 (-0.031) |
| Disturbance ($d = 0.2$) | 1.200 (+0.200) | 0.840 (+0.040) |

Notice what is being compared: how far the output moves, not how far it ends from the reference. The closed loop still carries its offset from the reference, and with a disturbance of the opposite sign its absolute error would be larger than the open loop's. What feedback has done is make the output move about five times less when the plant or the load changes.

### 4.2 One factor behind all three results

The factor of five is not a coincidence of the numbers chosen. Define the **loop gain** at steady state as $L_0 = bk/a$: the controller gain $k$ times the plant's steady-state gain $b/a$, which is $G(0)$ in the notation of the first entry. Then, for $a > 0$, three results of this entry are governed by the same factor $1/(1 + L_0) = a/(a + bk)$.

- **Offset.** The steady-state error of Section 2.3 is $r - x_{ss} = r/(1 + L_0)$.
- **Disturbance.** A constant disturbance moves the output by $d/(a + bk)$ in closed loop and $d/a$ in open loop: the ratio is $1/(1 + L_0)$.
- **Plant error.** The relative change of the settled output per relative change of $a$ is the derivative $(a/x_{ss})\,\partial x_{ss}/\partial a$. For the open loop, $x_{ss} = bu/a$ gives $-1$: a 1% error in $a$ moves the output by 1%. For the closed loop, $x_{ss} = bk\,r/(a + bk)$ gives $-a/(a + bk) = -1/(1 + L_0)$.

With $a = b = 1$ and $k = 4$, $L_0 = 4$ and the factor is $1/5$. For the 20% change of $a$ above, the derivative predicts relative shifts of $-20\%$ in open loop and $-4\%$ in closed loop; the simulation gives $-16.7\%$ and $-3.9\%$, close to the prediction because the derivative describes small changes. The general lesson is that a high loop gain buys accuracy against model errors and disturbances, and proportional feedback pays for it with an offset of the same factor. Removing the offset itself takes more than proportional action, typically an integrator.

## 5. What this model hides

> A higher gain is not automatically better. The first-order model has no delay, no actuator limit and no measurement noise, and real systems have all three.

For a stable plant ($a > 0$) this model makes every positive gain stable, and every increase of the gain an improvement: faster, less sensitive and with a smaller offset, although the offset never reaches zero. Each of the missing effects puts an upper limit on $k$.

- **Delay.** Delays and unmodeled dynamics can turn a large gain into oscillation or instability. A controller implemented on a computer is one source: it samples $x$ and holds $u$ constant between samples, so it always acts on slightly old information. The [digital-control entry of the signal-processing series](/blog/from-signal-processing-to-digital-control) shows that for $a = b = 1$ sampled every 0.1 s, the loop becomes unstable for $k$ above about 20.
- **Actuator limits.** At the instant of a step from rest the error is $r$, so the controller asks for $u = kr$: nine times the open-loop input for $k = 9$. A real actuator saturates, the input cannot grow without bound, and the response is then slower than the linear model predicts.
- **Measurement noise.** If the sensor reports $x + n$, the input becomes $k(r - x - n)$: the noise reaches the plant multiplied by $k$.

Treating $k$ as freely adjustable is therefore an artifact of the model. Later entries in this series use state-space descriptions to reason about these limits more carefully: the [fourth](/blog/stability-and-eigenvalues) on stability, and the [fifth](/blog/state-feedback-controller-design) on what a state-feedback design assumes about the actuator, the measurements and the model.

## 6. Summary

| Question | Answer for $\dot{x} = -ax + bu$ with $u = k(r - x)$ |
| --- | --- |
| What happens to speed? | The pole moves from $-a$ to $-(a + bk)$; the time constant falls to $1/(a + bk)$ |
| What happens to stability? | An unstable plant ($a < 0$) is stabilized by any $k > -a/b$ |
| Where does the output settle? | At $bk\,r/(a + bk)$: an offset of $r/(1 + L_0)$, with loop gain $L_0 = bk/a$ |
| How much do plant errors and disturbances move it? | $1/(1 + L_0)$ times as much as in open loop |
| What removes the offset? | An integrator, not a larger proportional gain |
| What limits the gain? | Delay, actuator saturation and measurement noise, none of which the model contains |

Proportional feedback on one variable already shows the main effects of feedback: faster response, stabilization and lower sensitivity, paid for with an offset and limited by what the model leaves out. Real systems have more than one internal variable, and a single first-order equation cannot describe a mass on a spring or a robot joint. The [next entry](/blog/state-space-models-primer) introduces state-space models, which describe such systems with one matrix equation and show that their stability is decided by the eigenvalues of a matrix, just as the stability of this loop was decided by the sign of $a + bk$.
