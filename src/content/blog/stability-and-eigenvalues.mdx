The [primer on state-space models](/blog/state-space-models-primer) ended with a single claim: the free response of $\dot{x} = Ax$ decays for every initial condition if and only if every eigenvalue of $A$ has a negative real part. This entry explains why that is true, what else the eigenvalues say about the response, and where they stop being enough. It assumes the material of the earlier entries (the vocabulary of the [first entry](/blog/introduction-to-control-systems), the first-order loop of the [second](/blog/feedback-and-system-behavior), and the $(A, B, C, D)$ form of the third) and basic linear algebra: matrix products, inverses, eigenvalues and eigenvectors.

Throughout, time $t$ is in seconds and every eigenvalue is in radians per second (written rad/s, or simply 1/s for a real eigenvalue). The running example is the mass-spring-damper of the primer, with $m = 1$ kg, $c = 0.5$ N·s/m and $k = 4$ N/m. The Python examples use Python 3 and numpy (run with numpy 2.5).

## What "stable" means

The [first entry](/blog/introduction-to-control-systems) gave an informal requirement: bounded inputs and disturbances should produce bounded outputs. For a state-space model there are two different questions hiding in that sentence, and it pays to separate them from the start.

An **equilibrium** is a state at which the system stays when nothing pushes it. For $\dot{x} = Ax$ the origin $x = 0$ is always an equilibrium, because $A\,0 = 0$. The first question is about what happens near it:

- The equilibrium is **asymptotically stable** if every free response, from every initial condition, decays to zero as $t \to \infty$. For linear systems this is also called **internal stability**, because it concerns every internal state variable, not just the output.
- It is **marginally stable** if every free response stays bounded but some do not decay.
- It is **unstable** if some free response grows without bound.

The second question is about inputs and outputs. A system is **bounded-input, bounded-output stable** (BIBO stable) if every bounded input signal produces a bounded output signal, starting from rest. This is the requirement the first entry stated. The two notions usually agree, but not always, and the section on hidden modes below shows when they differ.

Both are properties of the model. A physical system is "stable" only in the sense that a model of it is, under the assumptions the model makes.

## The free response is a sum of modes

Start with the scalar case from the [second entry](/blog/feedback-and-system-behavior): $\dot{x} = \lambda x$ has the solution $x(t) = e^{\lambda t}x(0)$. If $\lambda < 0$ it decays with time constant $1/|\lambda|$; if $\lambda > 0$ it grows; if $\lambda = 0$ it stays where it started.

For a matrix equation $\dot{x} = Ax$ with $n$ states, suppose $A$ has $n$ linearly independent eigenvectors $v_1, \dots, v_n$ with eigenvalues $\lambda_1, \dots, \lambda_n$, so that $A v_i = \lambda_i v_i$. Collect them in the matrix $V = [v_1 \; \cdots \; v_n]$ and the diagonal matrix $\Lambda = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$. Then $AV = V\Lambda$, so

$$
A = V \Lambda V^{-1}.
$$

A matrix that can be written this way is called **diagonalizable**. Now change variables to $z = V^{-1}x$, the coordinates of the state along the eigenvectors. Substituting $x = Vz$ into $\dot{x} = Ax$ gives

$$
V\dot{z} = AVz = V\Lambda z \quad\Longrightarrow\quad \dot{z} = \Lambda z.
$$

Because $\Lambda$ is diagonal, the $n$ equations separate: $\dot{z}_i = \lambda_i z_i$, each a scalar equation with solution $z_i(t) = e^{\lambda_i t} z_i(0)$. Transforming back,

$$
x(t) = \sum_{i=1}^{n} z_i(0)\, e^{\lambda_i t}\, v_i, \qquad z(0) = V^{-1}x(0).
$$

Each term is a **mode**: a fixed direction $v_i$ in state space, multiplied by a scalar function of time $e^{\lambda_i t}$. The initial condition decides how much of each mode is present; the eigenvalue decides what that mode does over time. Written as a matrix, this is

$$
x(t) = e^{At}x(0), \qquad e^{At} = V\, \operatorname{diag}\!\left(e^{\lambda_1 t}, \dots, e^{\lambda_n t}\right) V^{-1},
$$

which is the matrix exponential the primer quoted.

The stability claim follows at once. If every $\lambda_i$ has a negative real part, every term decays and $x(t) \to 0$ from every starting point. If some $\lambda_i$ has a positive real part, starting along $v_i$ (so that only that mode is present) gives a response that grows without bound.

The formula can be checked numerically against a direct integration of the differential equation. The script builds $e^{At}$ from the eigen-decomposition for the running example and compares it with a fine fourth-order Runge-Kutta integration (the method of the [notes on numerical integration](/blog/numerical-integration-notes)):

```python
import numpy as np

m, c, k = 1.0, 0.5, 4.0
A = np.array([[0.0, 1.0],
              [-k / m, -c / m]])

lam, V = np.linalg.eig(A)
def expm_modal(t):
    return (V @ np.diag(np.exp(lam * t)) @ np.linalg.inv(V)).real

def rk4(x, T, h=1e-4):
    for _ in range(round(T / h)):
        k1 = A @ x
        k2 = A @ (x + h / 2 * k1)
        k3 = A @ (x + h / 2 * k2)
        k4 = A @ (x + h * k3)
        x = x + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
    return x

x0 = np.array([1.0, 0.0])        # displaced by 1 m, at rest
print(lam)                       # [-0.25+1.98431348j -0.25-1.98431348j]
print(expm_modal(1.0) @ x0)      # [-0.223098   -1.43759169]
print(rk4(x0, 1.0))              # [-0.223098   -1.43759169]
```

The two results agree to all printed digits. The eigenvalues are complex, yet the state is real: the next section explains why.

## Real eigenvalues, complex pairs and damping

A real eigenvalue $\lambda = -\sigma$ with $\sigma > 0$ contributes a pure exponential decay with time constant $1/\sigma$. After one time constant the mode has fallen to $e^{-1} \approx 37\%$ of its initial size, and after four it is below 2%.

When $A$ is real, complex eigenvalues come in conjugate pairs $\lambda = -\sigma \pm j\omega_d$, with conjugate eigenvectors, where $j$ is the imaginary unit. The two modes of a pair always appear together with conjugate weights, so their sum is real. Using Euler's formula $e^{j\omega_d t} = \cos\omega_d t + j\sin\omega_d t$, the pair contributes a term of the form

$$
e^{-\sigma t}\bigl(a\cos\omega_d t + b\sin\omega_d t\bigr)
$$

with real vectors $a$ and $b$. The **real part** $-\sigma$ sets the exponential envelope and so the decay rate; the **imaginary part** $\omega_d$ is the angular frequency of the oscillation, in rad/s.

This connects the eigenvalues directly to the second-order model of the [first entry](/blog/introduction-to-control-systems). The characteristic polynomial $s^2 + 2\zeta\omega_n s + \omega_n^2$ has, for $0 < \zeta < 1$, the roots

$$
\lambda = -\zeta\omega_n \pm j\,\omega_n\sqrt{1 - \zeta^2}.
$$

So:

- the **natural frequency** $\omega_n = |\lambda|$ is the distance of the eigenvalue from the origin of the complex plane;
- the **damping ratio** $\zeta = \sigma/|\lambda|$ is the cosine of the angle between the eigenvalue and the negative real axis;
- the **damped frequency** $\omega_d = \omega_n\sqrt{1 - \zeta^2}$ is the imaginary part.

For the mass-spring-damper, comparing $s^2 + (c/m)s + k/m$ with $s^2 + 2\zeta\omega_n s + \omega_n^2$ gives

$$
\omega_n = \sqrt{k/m} = 2 \text{ rad/s}, \qquad \zeta = \frac{c}{2\sqrt{mk}} = 0.125.
$$

The eigenvalues $-0.25 \pm 1.984j$ printed above match: $\zeta\omega_n = 0.25$ and $\omega_n\sqrt{1 - \zeta^2} = 1.984$. With the formulas of the first entry, a step input to this lightly damped system would overshoot by $\exp(-\pi\zeta/\sqrt{1 - \zeta^2}) \approx 67.3\%$ and take about $4/(\zeta\omega_n) = 16$ s to settle within 2%. Those numbers are why the [next entry](/blog/state-feedback-controller-design) uses this system as its example: it is stable, but slow to settle and badly damped, and feedback can move its eigenvalues somewhere better.

The general picture is worth remembering as a map of the complex plane.

| Eigenvalue location | Mode | Behavior |
| --- | --- | --- |
| Negative real axis, $\lambda = -\sigma$ | $e^{-\sigma t}$ | Decays without oscillation, time constant $1/\sigma$ |
| Left half-plane, complex pair | $e^{-\sigma t}\cos(\omega_d t + \varphi)$ | Decaying oscillation; damping ratio $\sigma/\lvert\lambda\rvert$ |
| Imaginary axis, $\lambda = \pm j\omega$ | $\cos(\omega t + \varphi)$ | Sustained oscillation of constant amplitude |
| Origin, $\lambda = 0$ | constant | Stays where it started (an integrator) |
| Right half-plane | $e^{+\sigma t}$, possibly oscillating | Grows without bound |

Two practical readings follow. Eigenvalues further to the left decay faster, so the **slowest mode**, the one nearest the imaginary axis, dominates how long the response takes to settle. And eigenvalues close to the imaginary axis relative to their distance from the origin, that is, with a small damping ratio, oscillate many times before they die out.

## Marginal cases and repeated eigenvalues

Eigenvalues on the imaginary axis sit on the boundary between decay and growth, and they are where the simple rule needs care.

**Simple eigenvalues on the axis.** Remove the damper from the example ($c = 0$). The eigenvalues become $\pm 2j$ and the mass oscillates forever with constant amplitude. The response is bounded but does not decay: the origin is marginally stable. A single integrator, $\dot{x} = u$ with $u = 0$, has the eigenvalue $0$ and simply holds its initial value, which is also marginally stable.

**Repeated eigenvalues.** Not every matrix is diagonalizable. The **double integrator**, a mass with no spring and no damper, has

$$
A = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix},
$$

with the eigenvalue $0$ repeated twice but only one independent eigenvector, $[1 \;\; 0]^\top$. Its free response is $q(t) = q(0) + \dot{q}(0)\,t$: a mass given an initial velocity keeps moving, and its position grows linearly without bound. So two eigenvalues at the origin, which individually would only give constants, together give an unbounded response. The general statement replaces the diagonal form by the **Jordan form**: when an eigenvalue $\lambda$ is repeated without a full set of eigenvectors, the modes include terms $t\,e^{\lambda t}$, $t^2 e^{\lambda t}$, and so on.

This sharpens the rule:

- **Asymptotically stable** if and only if every eigenvalue has a negative real part. Repeated eigenvalues do no harm here, because $t^p e^{\lambda t}$ still decays when the real part of $\lambda$ is negative.
- **Marginally stable** if no eigenvalue has a positive real part and every eigenvalue on the imaginary axis has as many independent eigenvectors as its multiplicity.
- **Unstable** otherwise.

Marginal stability is fragile. An arbitrarily small change in the model, such as a little negative damping, can move an eigenvalue from the axis into the right half-plane, so a design that relies on it is relying on the model being exact.

## Eigenvalues are not the whole story: transient growth

Stable eigenvalues guarantee that the response eventually decays. They do not say how large it gets on the way. Consider

$$
A = \begin{bmatrix} -1 & 10 \\ 0 & -2 \end{bmatrix},
$$

whose eigenvalues, read off the diagonal of this triangular matrix, are $-1$ and $-2$: comfortably stable. Start at $x(0) = [0 \;\; 1]^\top$. The second state decays as $x_2 = e^{-2t}$, but it drives the first, and solving $\dot{x}_1 = -x_1 + 10e^{-2t}$ gives

$$
x_1(t) = 10\bigl(e^{-t} - e^{-2t}\bigr),
$$

which rises from zero to a peak of $2.5$ at $t = \ln 2 \approx 0.69$ s before decaying. A state that started with size 1 grew to about 2.5 times that size before it shrank.

```python
import numpy as np

A = np.array([[-1.0, 10.0], [0.0, -2.0]])
lam, V = np.linalg.eig(A)
expm = lambda t: (V @ np.diag(np.exp(lam * t)) @ np.linalg.inv(V)).real

x0 = np.array([0.0, 1.0])
ts = np.linspace(0, 6, 6001)
norms = [np.linalg.norm(expm(t) @ x0) for t in ts]
i = int(np.argmax(norms))
print(round(norms[i], 3), ts[i])      # 2.513 0.683
```

The largest Euclidean norm of the state is $2.513$, slightly larger than the peak of $x_1$ alone because $x_2$ is not yet zero at that moment. The effect comes from eigenvectors that are nearly parallel: here $v_1 = [1 \;\; 0]^\top$ and $v_2 \propto [-10 \;\; 1]^\top$ point in almost the same direction, so a small initial state can be a difference of two large modal components that decay at different rates. Matrices whose eigenvectors are orthogonal (**normal** matrices, such as symmetric ones) cannot do this; strongly non-normal ones can show transient growth of many orders of magnitude.

For control this matters because a real system has limits the linear model does not: an actuator saturates, a structure yields, a linearization stops being valid. A response that is "stable" by its eigenvalues but grows a hundredfold first may break one of those limits.

## Internal stability and input-output stability

So far there was no input. Adding one brings in the input-output description that the first entry used without deriving.

The **Laplace transform** turns a signal $f(t)$, defined for $t \ge 0$, into a function $F(s) = \int_0^\infty f(t)e^{-st}\,dt$ of a complex variable $s$. Its useful property here is that differentiation becomes multiplication: the transform of $\dot{f}$ is $sF(s) - f(0)$. Taking transforms of $\dot{x} = Ax + Bu$, $y = Cx + Du$ with the system starting at rest ($x(0) = 0$) gives $sX(s) = AX(s) + BU(s)$, so

$$
Y(s) = G(s)\,U(s), \qquad G(s) = C\,(sI - A)^{-1}B + D.
$$

$G(s)$ is the **transfer function**: the input-output form of the same system. For the mass-spring-damper,

$$
G(s) = \frac{1}{ms^2 + cs + k} = \frac{1}{s^2 + 0.5s + 4},
$$

which is a ratio of polynomials in $s$. The roots of its denominator are its **poles** and the roots of its numerator its **zeros**. Because $(sI - A)^{-1} = \operatorname{adj}(sI - A)/\det(sI - A)$, every pole of $G(s)$ is a root of $\det(sI - A)$, that is, an eigenvalue of $A$. For this example the poles and the eigenvalues are the same pair, $-0.25 \pm 1.984j$.

A transfer function with all its poles in the open left half-plane is BIBO stable. So if the system is internally stable it is also BIBO stable. The converse can fail, because a pole of $G(s)$ is always an eigenvalue but an eigenvalue need not appear as a pole. Take

$$
A = \begin{bmatrix} 1 & 0 \\ 0 & -2 \end{bmatrix}, \quad
B = \begin{bmatrix} 0 \\ 1 \end{bmatrix}, \quad
C = \begin{bmatrix} 0 & 1 \end{bmatrix}, \quad D = 0.
$$

Here $G(s) = 1/(s + 2)$, which is BIBO stable. But $A$ has the eigenvalue $+1$: the first state obeys $\dot{x}_1 = x_1$, grows from any nonzero initial value, and is neither moved by the input nor seen in the output. Two properties describe exactly this situation:

- A system is **controllable** if the input can steer the state from any initial value to any final value in finite time. A mode the input cannot affect makes the system uncontrollable.
- A system is **observable** if the initial state can be worked out from the input and output over a finite interval. A mode that never appears in the output makes it unobservable.

An eigenvalue that is uncontrollable or unobservable can disappear from $G(s)$, in which case it appears as a pole-zero cancellation if $G(s)$ is computed from a larger model. When every mode is both controllable and observable, the poles of $G(s)$ are exactly the eigenvalues of $A$, and the two notions of stability coincide. The [next entry](/blog/state-feedback-controller-design) gives a test for controllability, because it is precisely the condition under which feedback can move every eigenvalue.

The lesson for design: checking only the transfer function can hide an unstable internal mode. A cancelled unstable pole still exists in the hardware, and noise or a small initial condition will excite it.

## Stability in discrete time

A controller implemented on a computer sees the system only at sampling instants $t = kT$, with **sampling period** $T$. If the input is held constant between samples, the exact solution over one period gives a discrete-time model

$$
x[k+1] = A_d\,x[k] + B_d\,u[k], \qquad A_d = e^{AT},
$$

where $x[k]$ means $x(kT)$. The free response is $x[k] = A_d^{\,k}x[0]$, and the same modal argument applies with powers in place of exponentials: each mode is multiplied by its eigenvalue $\mu_i$ at every step. So the discrete-time rule is:

- asymptotically stable if and only if every eigenvalue of $A_d$ has magnitude less than 1 (lies strictly inside the **unit circle** of the complex plane).

The eigenvalues of $A_d = e^{AT}$ are $\mu_i = e^{\lambda_i T}$, and $|e^{\lambda T}| = e^{\operatorname{Re}(\lambda)\,T}$, so a continuous eigenvalue in the left half-plane maps to a discrete one inside the unit circle. For the running example with $T = 0.1$ s, $\mu = e^{(-0.25 \pm 1.984j)(0.1)} \approx 0.956 \pm 0.192j$, with magnitude $e^{-0.025} \approx 0.975$.

The exact map preserves stability. An approximate one need not, which is the point of the [notes on numerical integration](/blog/numerical-integration-notes). Explicit Euler replaces $e^{\lambda T}$ by $1 + \lambda T$. For a complex eigenvalue $\lambda = -\sigma + j\omega_d$,

$$
|1 + \lambda T|^2 = (1 - \sigma T)^2 + (\omega_d T)^2 < 1
\quad\Longleftrightarrow\quad
T < \frac{2\sigma}{\sigma^2 + \omega_d^2} = \frac{2\sigma}{|\lambda|^2}.
$$

For the example, $2(0.25)/4 = 0.125$ s. With $T = 0.1$ s the Euler factor has magnitude $0.995$ and the simulated oscillator decays, slowly; with $T = 0.5$ s it has magnitude $1.32$ and the simulation grows, although the physical system is stable. Lightly damped eigenvalues are especially demanding, because $\sigma$ is small compared with $|\lambda|$.

## Nonlinear systems: stability by linearization

Real plants are rarely linear. The eigenvalue test still applies locally. For a nonlinear system $\dot{x} = f(x)$ with an equilibrium $x^*$ (so $f(x^*) = 0$), small deviations $\delta x = x - x^*$ approximately obey

$$
\dot{\delta x} \approx J\,\delta x, \qquad J = \left.\frac{\partial f}{\partial x}\right|_{x = x^*},
$$

where $J$ is the **Jacobian** matrix of partial derivatives. **Lyapunov's indirect method** states that if every eigenvalue of $J$ has a negative real part, the equilibrium of the nonlinear system is locally asymptotically stable; if some eigenvalue has a positive real part, it is unstable. If the largest real part is exactly zero, the linearization is inconclusive and the nonlinear terms decide.

A pendulum shows both outcomes. With angle $\theta$ measured from the hanging-down position (in radians), length $L$, gravitational acceleration $g$ and a viscous damping coefficient $d$ (per second),

$$
\ddot{\theta} = -\frac{g}{L}\sin\theta - d\,\dot{\theta}.
$$

With states $x_1 = \theta$, $x_2 = \dot{\theta}$, the equilibria are $\theta = 0$ (hanging down) and $\theta = \pi$ (balanced upright). The derivative of $\sin\theta$ is $\cos\theta$, which is $+1$ at the bottom and $-1$ at the top, so

$$
J_{\text{down}} = \begin{bmatrix} 0 & 1 \\ -g/L & -d \end{bmatrix}, \qquad
J_{\text{up}} = \begin{bmatrix} 0 & 1 \\ g/L & -d \end{bmatrix}.
$$

With $g = 9.81$ m/s², $L = 1$ m and $d = 0.5$ s⁻¹:

```python
import numpy as np

g, L, d = 9.81, 1.0, 0.5
print(np.linalg.eigvals([[0, 1], [-g / L, -d]]))   # [-0.25+3.12209865j -0.25-3.12209865j]
print(np.linalg.eigvals([[0, 1], [ g / L, -d]]))   # [ 2.89205347 -3.39205347]
```

Hanging down, the pendulum is a damped oscillator, stable. Balanced upright, one eigenvalue is $+2.89$ s⁻¹: a small tilt grows by a factor $e$ about every $0.35$ s until the linear model no longer applies. The same physical system has a stable and an unstable equilibrium, and the conclusion holds only near each one. This is the "assumptions and limits of a model" that the series objectives ask the reader to keep in view: a controller designed on the linearized model is designed for small deviations.

## Exercises

1. A system has eigenvalues $-0.5$, $-3 \pm 4j$. Which mode dominates the settling time, and roughly how long does the response take to fall below 2% of its initial size? What are $\omega_n$ and $\zeta$ of the complex pair?

<details>
<summary>Answer</summary>

The slowest mode is $-0.5$ (closest to the imaginary axis), with time constant 2 s, so roughly four time constants, about 8 s. For the pair, $\omega_n = |{-3} + 4j| = 5$ rad/s and $\zeta = 3/5 = 0.6$; it settles in about $4/3 \approx 1.3$ s and does not dominate.

</details>

2. For the mass-spring-damper with $m = 1$ kg and $k = 4$ N/m, what damping coefficient $c$ gives a damping ratio of $0.7$? Where are the eigenvalues then?

<details>
<summary>Answer</summary>

$\zeta = c/(2\sqrt{mk}) = c/4$, so $c = 2.8$ N·s/m. The eigenvalues are $-\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2} = -1.4 \pm 1.428j$.

</details>

3. Is the system $A = \begin{bmatrix} 0 & 1 \\ 0 & -1 \end{bmatrix}$ asymptotically stable, marginally stable or unstable? Describe its free response.

<details>
<summary>Answer</summary>

The eigenvalues are $0$ and $-1$, both simple, with no positive real part: marginally stable. The second state decays as $e^{-t}$, and the first integrates it, approaching the constant $x_1(0) + x_2(0)$. It does not return to the origin.

</details>

4. Using the Euler condition above, find the largest sampling period for which explicit Euler simulation of the upright pendulum's *stable* eigenvalue $-3.39$ s⁻¹ decays. Why is no step size able to make the simulation of the eigenvalue $+2.89$ s⁻¹ decay, and why is that correct?

<details>
<summary>Answer</summary>

For a real eigenvalue $\lambda = -\sigma$ the condition is $|1 - \sigma T| < 1$, so $T < 2/\sigma = 2/3.39 \approx 0.59$ s. For $\lambda = +2.89$, $1 + \lambda T > 1$ for every $T > 0$, so the simulated mode always grows, which is the correct behavior: the true mode grows too.

</details>

5. In the hidden-mode example, which property fails: controllability, observability, or both? What would you see if you measured $x_1$ directly?

<details>
<summary>Answer</summary>

Both: the input does not enter $\dot{x}_1$, and $x_1$ does not appear in $y$. Measuring $x_1$ would reveal a state growing as $e^{t}$ from any nonzero initial value, regardless of the input.

</details>

## Summary

| Question | Answer |
| --- | --- |
| What is a mode? | A term $e^{\lambda_i t}v_i$ of the free response: an eigenvector direction multiplied by an exponential in its eigenvalue. |
| When is $\dot{x} = Ax$ asymptotically stable? | When every eigenvalue of $A$ has a negative real part. |
| What do the real and imaginary parts mean? | The real part sets the decay rate; the imaginary part sets the oscillation frequency in rad/s. |
| How do eigenvalues relate to $\omega_n$ and $\zeta$? | $\omega_n = \lvert\lambda\rvert$ and $\zeta = -\operatorname{Re}(\lambda)/\lvert\lambda\rvert$ for a complex pair. |
| What about eigenvalues on the imaginary axis? | Marginal: bounded if each has a full set of eigenvectors, unbounded (as $t^p$) if repeated without one. |
| Do stable eigenvalues bound the transient? | No. Non-normal matrices can amplify the state temporarily before it decays. |
| How do poles relate to eigenvalues? | Every pole of $G(s) = C(sI - A)^{-1}B + D$ is an eigenvalue of $A$; they coincide when the system is controllable and observable. |
| What changes in discrete time? | Stability requires eigenvalues of $A_d$ inside the unit circle; $e^{\lambda T}$ maps the left half-plane there, approximations may not. |
| What about nonlinear systems? | The Jacobian's eigenvalues decide local stability of an equilibrium, except when the largest real part is zero. |

The eigenvalues of $A$ are fixed by the physical system. The [next entry](/blog/state-feedback-controller-design) shows how feedback from the measured state replaces $A$ by a new matrix whose eigenvalues the designer chooses, and what that choice assumes about the model and the measurements.
